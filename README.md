# Real Estate Price Prediction

This project is a Real Estate Price Prediction tool built with React for the frontend and Flask for the backend. The tool estimates the price of a property based on its location, size (in BHK), the number of bathrooms, and total area in square feet.

## Features

- **Location Selector**: A dropdown list of available locations fetched from the backend.
- **Form Input**: Users can input the number of BHK, bathrooms, and total area to predict the property price.
- **Real-time Price Prediction**: After the user submits the form, the estimated price is displayed.
- **Error Handling**: Displays error messages if inputs are missing or if there's a problem with the backend request.

## Technologies Used

- **Frontend**: React, Axios
- **Backend**: Flask
- **Styling**: CSS (Responsive design for a better user experience)
- **Cross-Origin Resource Sharing (CORS)**: Enabled for seamless communication between frontend and backend during development.
